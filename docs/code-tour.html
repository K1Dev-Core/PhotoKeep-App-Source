PhotoKeep เป็น desktop app; หน้า Vue ไม่ยิง Go REST API แต่เรียกเมธอดที่ Wails bind ให้โดยตรง

Frontend

App bridge + service

frontend/app/utils/openvsx-theme.ts · parse JSONC แล้วตรวจ object
function parseJSONC(text: string, filename: string): unknown {
  const errors: ParseError[] = []
  const value: unknown = parse(text, errors, { allowTrailingComma: true })
  if (errors.length || !value || typeof value !== 'object' || Array.isArray(value)) {
    throw new Error(`${filename} ไม่ใช่ JSON/JSONC ที่ถูกต้อง`)
  }
  return value
}

นาที 6 · ค้นหา

นาที 8 · สรุป

แยก Wails bridge จาก Gateway HTTP. ตรวจ endpoint/model/index ก่อนพูดถึง deployment.
