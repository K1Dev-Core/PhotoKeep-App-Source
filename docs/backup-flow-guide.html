AI CAPTION PIPELINE · ภาพ → GATEWAY → คำบรรยาย + TAGS
วิเคราะห์ภาพ: ส่งภาพไป AI อย่างไร
เส้นนี้สร้างคำบรรยายและแท็กที่บันทึกใน SQLite โดยตรงจากแอป PhotoKeep ผ่าน Wails ไปยัง AI Gateway ที่ตั้งไว้ งานนี้แยกจากการทำ image embedding ซึ่งใช้สำหรับค้นหาตามความหมาย
ประเด็นสำคัญ: แอปส่งภาพทีละไฟล์ด้วย multipart field file ไปที่ /v1/analyze แต่หลาย worker ทำคำขอพร้อมกันตามค่า concurrency ที่ Gateway แจ้งจาก /health ไม่ได้ส่งภาพทั้งชุดเป็น batch request


IMAGE EMBEDDING INDEX · ภาพ → VECTOR → SQLITE
เตรียมดัชนีความหมายสำหรับค้นหา
หลังสำรองสำเร็จ ระบบเริ่มทำ embedding แยกจากคำบรรยาย ภาพที่ยังไม่มีเวกเตอร์จะถูกย่อและส่งไปยัง /v1/embed/image แล้วเก็บเวกเตอร์และชื่อโมเดลไว้ในฐานข้อมูล เครื่องจะคำนวณ cosine similarity ในเครื่องเมื่อมีคำค้น
