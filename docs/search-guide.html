คำค้น → ผลลัพธ์
ถ้า semantic ใช้ไม่ได้ระบบยังแสดงผลค้นคำตรงจาก SQLite ได้ ไม่จำเป็นต้องรอ API สำเร็จ

หนึ่งคำค้นผ่านอะไรบ้าง

การค้นคำตรงเริ่มก่อนเพื่อให้มีผลเร็ว ส่วน semantic จะเพิ่มรูปที่คำในคำอธิบายไม่ได้ตรงกับข้อความค้น แต่เนื้อหาภาพใกล้เคียงกัน

1

รับคำค้น

แอปตัดช่องว่าง แล้วเรียก searchPage พร้อมตัวกรองแท็กและหน้าผลลัพธ์

2

หาแบบตรง

แยกคำภาษาไทย แล้วค้นใน SQLite FTS5 ชนิด trigram จากชื่อไฟล์ คำอธิบาย และแท็ก

3

หาแบบความหมาย

ส่งข้อความไป /v1/embed/text แล้วคำนวณ cosine กับเวกเตอร์รูปในฐานข้อมูล รุ่นโมเดลต้องตรงกัน

4

รวมและแบ่งหน้า

รวมลำดับจากสองทาง เรียงคะแนนรวม แล้วส่งเฉพาะหน้าที่ต้องแสดงให้หน้าแอป

คะแนนคำตรง = คำในแท็ก × 5 + ชื่อไฟล์ × 3 + คำอธิบาย × 2 พร้อมโบนัสเมื่อวลีตรงกันทั้งวลี
คะแนน semantic = dot(query, image) / (‖query‖ × ‖image‖)
คะแนนรวม = reciprocal-rank fusion โดยให้อันดับคำตรงน้ำหนัก 2 เท่าของ semantic

โค้ดส่วนไหนทำหน้าที่อะไร

เส้นทางเริ่มจากแอปหลัก แยกเป็นตัวค้น SQLite และ client สำหรับ Gateway แล้วกลับมารวมอันดับ

app.go

ประสานการค้นหา

searchPage เรียกคำตรง ตรวจว่ามี embedding หรือไม่ ขอ embedding ของข้อความ และรวมผลด้วย combineSearchResults

internal/photokeep/photos_search.go

ค้นคำตรงใน SQLite

searchPageRanked คัดผู้สมัครจากดัชนี photo_search แล้วเรียงตามจำนวนคำที่ตรง น้ำหนัก และเวลาสำรอง

internal/photokeep/search_terms.go

ตัดคำและให้คะแนน

ใช้ตัวตัดคำไทยทั่วไปเพื่อแยกคำ ไม่ได้มีรายการชื่อสัตว์หรือพจนานุกรมคำพ้องเฉพาะในไฟล์นี้

internal/photokeep/embeddings.go

สร้างและเทียบเวกเตอร์

ManagedEmbeddingClient เรียก embed ข้อความ/รูป ส่วน SemanticPhotoScores คำนวณ cosine similarity กับรูปที่ใช้โมเดลเดียวกัน

ค้นข้อความ: app.go → photos_search.go + /v1/embed/text → embeddings.go
เตรียมเวกเตอร์รูป: image_ai.go / embeddings.go → /v1/embed/image → บันทึกใน SQLite

ทำไม “หมา” กับ “สุนัข” อาจได้ผลไม่เท่ากัน

ไม่มีคู่คำที่ฝังไว้ในโค้ด ระบบส่งแต่ละคำไปให้ embedding model ตีความ แล้วใช้คำตรงช่วยหาเพิ่ม

✓ สิ่งที่ระบบทำได้

ค้นคำและแนวคิดใกล้เคียง

ผล semantic มาจากคะแนนจริงระหว่างเวกเตอร์ข้อความกับเวกเตอร์ภาพ รายการเวกเตอร์ถูกเก็บไว้ จึงไม่ต้องเรียก embed ภาพใหม่ทุกครั้งที่ค้น

! ข้อจำกัดปัจจุบัน

ความหมายใกล้กันไม่ได้แปลว่ารายการเหมือนกัน

โมเดลอาจให้คะแนน “หมา” และ “สุนัข” คนละระดับ ระบบคัดผล semantic ที่คะแนนอย่างน้อย 0.70 และอยู่ภายใน 0.03 จากคะแนนสูงสุด แต่คำพ้องยังอาจได้จำนวนรูปต่างกัน

ถ้าต้องการให้คำพ้องมีผลเหมือนกันทุกครั้ง ต้องเพิ่มแหล่งคำพ้องที่แก้ไขได้ หรือใช้โมเดลค้นหา/จัดอันดับที่เข้าใจภาษาไทยดีขึ้น การปรับ threshold อย่างเดียวอาจเพิ่มรูปไม่เกี่ยวด้วย
